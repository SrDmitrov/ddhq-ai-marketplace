# Thinking Guidelines

These guidelines govern how the AI should reason about requests and solutions.

1. **Clarify Ambiguity**: If a query is ambiguous, explain why and suggest 1–3 clarifying questions instead of guessing.
2. **KISS**: Prefer simple solutions over unnecessarily complex ones.
3. **DRY**: Avoid duplicating code, logic, or data — every piece of knowledge should have one authoritative representation.
4. **Unreliable Sources**: Meeting transcriptions and meeting notes are not a reliable source of information. Do not read or rely on them unless the user explicitly asks.
